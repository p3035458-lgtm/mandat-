    npm install

## Запуск
    npm run dev      # при первом запуске сам выполнит npm install, затем откроет Vite на http://localhost:5173
    npm test         # проверка движка и новых механик без браузера

## Новые механики (блок «МЕХАНИКИ» и «ПАРТИЯ» в конце `src/game.js`)
- **Деньги за голоса** (раньше «гречка"): кнопка «Раздать деньги» в панели региона ($320 тыс., 2 часа). Сильнее всего в бедных регионах, слабо в столице и IT-регионе, повторная раздача в том же регионе слабее. Копит риск огласки, из-за него бывает скандал с четырьмя вариантами ответа. Соперники тоже иногда раздают деньги, их можно разоблачить.
- **Покушения**: письмо с угрозами → выбор защиты → возможное покушение с исходом по уровню охраны. Есть нападения на соперников и слухи «кому выгодно».
- **Партия и подкуп** (новая вкладка слева):
  - **Древо должностей** (17 постов). Секретарь открывает 9 региональных глав, председатель политсовета открывает молодёжное крыло, юротдел и службу безопасности. Кандидаты на пост различаются компетентностью и амбициями: честолюбивый даёт больше лояльности, но чаще предаёт.
  - **Лояльность элиты** (0–100) растёт при назначениях и медленно падает. Её тратят на «Поднять аппарат» в регионе и «Закрыть вопросы связями» (риск огласки −60%). Высокая лояльность даёт взносы, низкая повышает риск предательства. Содержание аппарата стоит денег каждую неделю.
  - **Подкуп** людей из окружения соперников: региональный координатор, человек из штаба (компромат и точный опрос), чиновник администрации региона. Риск огласки копится, при разоблачении «Дело о подкупе». Подкупленный координатор иногда переходит к вам и становится главой отделения.
  - Состояние партии лежит в `S.pty` (`S.party` в движке уже занято названием партии).

## Анимации
- `src/animations.css`: появление экранов (только при смене экрана), окна и варианты ответов событий, тосты, кнопки, медленный зум фото, бегущая рамка выбранного региона на карте, рост полосок опросов.
- `src/fx.js`: частицы 🌾 и всплывающие «+4,3 / −$180 тыс.» при раздаче гречки, цветная виньетка и тряска экрана при событиях («Покушение», «Угроза», «Скандал»), искры при сорванном нападении.
- Всё отключается, если в системе включено «уменьшить движение».

## Как устроено
- `src/assets.js`  — картинки (base64), вынесены как есть.
- `src/styles.css` — CSS из оригинала без изменений.
- `src/game.js`    — данные + движок + пока ещё HTML-экраны оригинала (ES-модуль, дубли функций убраны).
- `src/App.jsx`    — подписан на `render()` игры через `useSyncExternalStore`.
- `src/screens/`   — экраны, уже переписанные в JSX. Регистрация: `registerScreen('<phase>', Component)` в `screens/index.js`.
  Экран без компонента временно рисуется старой HTML-строкой, поэтому игра работает на каждом шаге.
